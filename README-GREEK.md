# Z9D-QAI

**Επιστημονική έρευνα τεχνητής νοημοσύνης και κυβερνοασφάλεια Z9D**

Το Z9D-QAI είναι ένα ανεξάρτητο πρόγραμμα έρευνας και ανάπτυξης με επικεφαλής τον Zoran Ljubić. Συνδυάζει επιστημονική τεχνητή νοημοσύνη, πειραματικές αρχιτεκτονικές QAGI, τοπικό λογισμικό ασφάλειας Windows και συστήματα για αυτόνομα και ρομποτικά περιβάλλοντα.

- **Επίσημη πλατφόρμα:** https://z9d-qai.com/
- **Matrixworld:** https://matrixworld.at/
- **Επικοινωνία:** Z9D.QAI@outlook.com
- **Υποστήριξη CSS/SRS:** Z9D-CSS@outlook.com

## Περιοχές έργου

- κατανόηση επιστημονικών κειμένων;
- εξαγωγή γνώσης και μεταδεδομένων;
- επιστημονικά σύνολα δεδομένων;
- επεξεργασία PDF και LaTeX;
- RAG, embeddings και επιστημονική ανάκτηση;
- πειραματικές αρχιτεκτονικές reasoning και memory;
- τοπική παρακολούθηση διεργασιών και δικτύου;
- ασφάλεια και άδειες ρομποτικών συστημάτων;
- πολυγλωσσική πλατφόρμα κοινότητας και marketplace Matrixworld.

## Z9D-CSS

Το Z9D Cyber Secure Service είναι τοπική εφαρμογή ασφάλειας για Windows. Ανάλογα με την έκδοση, μπορεί να παρακολουθεί διεργασίες, συνδέσεις δικτύου, απομακρυσμένες διευθύνσεις IP και συμβάντα συστήματος και να παρέχει καραντίνα ή αναφορές συμβάντων.

Αποθετήριο: [Z9D-QAI-CSS-Cyber-Secure-Service](https://github.com/Z9D-QAI/Z9D-QAI-CSS-Cyber-Secure-Service)
