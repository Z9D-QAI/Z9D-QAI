# Z9D-QAI

**Ricerca scientifica sull'intelligenza artificiale e cybersecurity Z9D**

Z9D-QAI è un progetto indipendente di ricerca e sviluppo guidato da Zoran Ljubić. Integra ricerca scientifica sull'IA, architetture sperimentali QAGI, software locale di sicurezza Windows e componenti per sistemi autonomi e robotici.

## Ambiti del progetto

- comprensione di testi scientifici;
- estrazione di conoscenza e metadati;
- dataset scientifici e elaborazione PDF/LaTeX;
- retrieval, embedding e pipeline RAG;
- architetture sperimentali di reasoning, memoria e cognizione;
- monitoraggio locale di processi e rete;
- sicurezza e licenza per sistemi robotici;
- piattaforma comunitaria e marketplace Matrixworld.

## Z9D-CSS

Z9D Cyber Secure Service è un'applicazione locale per Windows che può monitorare processi, connessioni di rete, indirizzi IP remoti, eventi di sistema e segnalare anomalie.

Le funzioni di quarantena, blocco automatico e analisi AI dipendono dall'edizione e dalla licenza acquistata.

Repository: [Z9D-QAI-CSS-Cyber-Secure-Service](https://github.com/Z9D-QAI/Z9D-QAI-CSS-Cyber-Secure-Service)
