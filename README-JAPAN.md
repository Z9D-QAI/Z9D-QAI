# Z9D-QAI

**科学AI研究とZ9Dサイバーセキュリティ**

Z9D-QAIは、Zoran Ljubić氏による独立した研究開発プロジェクトです。科学的AI研究、実験的なQAGIアーキテクチャ、ローカルWindowsセキュリティソフトウェア、自治システムおよびロボティクス向けコンポーネントを統合しています。

- **公式プラットフォーム:** https://z9d-qai.com/
- **Matrixworld:** https://matrixworld.at/
- **プロジェクト連絡先:** Z9D.QAI@outlook.com
- **CSS/SRSサポート:** Z9D-CSS@outlook.com

## プロジェクト領域

- 科学論文の理解と知識抽出;
- メタデータおよびデータセットの処理;
- PDFとLaTeXの構造化;
- 検索拡張生成（RAG）と埋め込み;
- 推論・メモリ・認知の実験的アーキテクチャ;
- ローカルプロセスとネットワーク監視;
- ロボットシステムのセキュリティとライセンス;
- Matrixworldコミュニティとマーケットプレイス。

## Z9D-CSS

Z9D Cyber Secure Serviceは、Windows向けのローカルセキュリティアプリケーションです。エディションに応じて、プロセス、ネットワーク接続、リモートIP、システムイベントの監視や隔離、インシデントレポートを提供できます。

リポジトリ: [Z9D-QAI-CSS-Cyber-Secure-Service](https://github.com/Z9D-QAI/Z9D-QAI-CSS-Cyber-Secure-Service)
