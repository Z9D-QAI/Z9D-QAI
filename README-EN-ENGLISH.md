# Z9D-QAI

**Scientific AI Research and Z9D Cyber Security**

Z9D-QAI is an independent research and development project by Zoran Ljubic. It brings together scientific AI research, experimental QAGI concepts, local Windows security software and systems for autonomous and robotic applications.

- **Official platform:** https://z9d-qai.com/
- **Matrixworld:** https://matrixworld.at/
- **Project e-mail:** Z9D.QAI@outlook.com
- **CSS/SRS support:** Z9D-CSS@outlook.com

## Project areas

| Area | Scope |
|---|---|
| Scientific AI | Scientific text understanding, knowledge extraction and retrieval |
| QAGI research | Experimental reasoning, cognition and memory architectures |
| Z9D-CSS | Local Windows process, network and threat monitoring |
| Z9D-SRS | Security and licensing concepts for robotics and control systems |
| Matrixworld | Multilingual community, AI, marketplace and mediation platform |

## Research focus

- scientific corpus normalization;
- metadata and full-text processing;
- PDF to structured JSON pipelines;
- retrieval, embeddings and RAG workflows;
- reasoning-model evaluation;
- modular memory and context architectures;
- experimental sensor and robotics integration.

The QAGI, quantum-inspired and bionic concepts describe ongoing research. They are not certified replacements for professional engineering, medical or safety decisions.

## Z9D-CSS

Z9D Cyber Secure Service is a local Windows security package for process and network monitoring.

- running-process monitoring;
- remote-IP and port analysis;
- Windows security-event review;
- threat-score indicators;
- quarantine and incident reports;
- optional local or API-based AI assistance;
- license-dependent blocking and response actions.

See [Z9D-QAI-CSS-Cyber-Secure-Service](https://github.com/Z9D-QAI/Z9D-QAI-CSS-Cyber-Secure-Service).

## Z9D-SRS

Z9D Secure Robotic System provides security, license and pairing concepts for:

- individual robots;
- ground-control stations;
- autonomous and AI-assisted systems;
- drones and unmanned platforms;
- industrial, OEM and fleet deployments.

## Responsible use

- operate software only on systems you own or are authorized to manage;
- review process, firewall and block actions before execution;
- do not disable security or activation controls to bypass licensing;
- protect license files, device IDs and logs;
- treat AI output and threat scores as supporting analysis;
- do not use robotic or remote-control functions against unauthorized systems or civilian targets.

No security product can guarantee complete protection against every current or future attack.
