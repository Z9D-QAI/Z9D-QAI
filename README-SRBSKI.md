# Z9D-QAI

**Naučno istraživanje veštačke inteligencije i Z9D sajber bezbednost**

Z9D-QAI je nezavisni projekat istraživanja i razvoja pod rukovodstvom Zorana Ljubića. Projekat povezuje naučnu veštačku inteligenciju, eksperimentalne QAGI arhitekture, lokalni Windows sigurnosni softver i komponente za autonomne i robotske sisteme.

- **Zvanična platforma:** https://z9d-qai.com/
- **Matrixworld:** https://matrixworld.at/
- **Kontakt projekta:** Z9D.QAI@outlook.com
- **CSS/SRS podrška:** Z9D-CSS@outlook.com

## Oblasti projekta

- razumevanje naučnih tekstova;
- izdvajanje znanja i metapodataka;
- priprema naučnih skupova podataka;
- obrada PDF i LaTeX sadržaja;
- retrieval, embedding i RAG procesi;
- eksperimentalne reasoning i memory arhitekture;
- lokalno nadgledanje procesa i mreže;
- bezbednost i licenciranje robotskih sistema;
- višejezična zajednica i marketplace platforma Matrixworld.

## Z9D-CSS

Z9D Cyber Secure Service je lokalna Windows aplikacija za nadgledanje procesa, mrežnih veza, udaljenih IP adresa i sistemskih događaja. Ovisno o izdanju, može obezbediti karantin, incidentni izveštaj i licence zavisno odblokiranje funkcija.

Repository: [Z9D-QAI-CSS-Cyber-Secure-Service](https://github.com/Z9D-QAI/Z9D-QAI-CSS-Cyber-Secure-Service)
