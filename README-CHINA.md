**科学人工智能研究与 Z9D 网络安全**

Z9D-QAI 是 Zoran Ljubic 发起的独立研究与开发项目，涵盖科学人工智能研究、实验性 QAGI 架构、本地 Windows 安全软件，以及自主系统和机器人系统组件。

## 项目领域

- 科学文本理解；
- 知识与元数据提取；
- 科学数据集工程；
- PDF 与 LaTeX 处理；
- 检索增强生成（RAG）、向量嵌入和科学检索；
- 推理、记忆及认知实验架构；
- 本地进程与网络监控；
- 机器人系统的安全与许可管理；
- Matrixworld 多语言社区与市场平台。
